# Пул pgxpool и реляционная схема

Пример создаёт `pgxpool.Pool`, разворачивает учебную RBAC-схему (`accounts`, `roles`, `permissions` и таблицы связей), идемпотентно добавляет данные и выполняет запросы с `JOIN`.

## Подготовка и запуск

Нужна база `ibs_pool` в PostgreSQL на `localhost:5432`, пользователь/пароль `ibs`/`ibs`. Для UUID-функции требуется современный PostgreSQL либо доступная функция `gen_random_uuid()`.

```bash
go run .
```

В production строку подключения передают через окружение, конфигурацию пула получают через `pgxpool.ParseConfig`, задают лимиты и проверяют готовность методом `Ping`.

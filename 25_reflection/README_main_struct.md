# main_struct.go

Рефлексия над структурами: поля, изменение и вложенность.

Показывает:

- обход полей итератором Go 1.26: `Value.Fields()`;
- метаданные поля: имя, тип, `PkgPath`;
- изменение полей через `FieldByName`, `CanSet`, `SetString` / `SetInt`;
- вложенную структуру (`Student` с embedded `Person`) и рекурсивный обзор полей.

Команда:

```bash
go run main_struct.go
```

Не запускайте `go run .`: в каталоге несколько независимых `main`.

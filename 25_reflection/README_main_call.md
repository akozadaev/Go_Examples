# main_call.go

Динамический вызов функций и методов через `reflect.Value.Call`.

Показывает:

- вызов обычной функции (`SayHello`) через `Call` со слайсом `[]reflect.Value`;
- вызов методов `Calculator` через `MethodByName`;
- диспетчеризацию операций по имени строки;
- variadic-функцию `Sum`: развёрнутые аргументы в `Call` и слайс в `CallSlice`.

Сейчас в `main` активна только демонстрация variadic; остальные блоки можно раскомментировать.

Команда:

```bash
go run main_call.go
```

Не запускайте `go run .`: в каталоге несколько независимых `main`.

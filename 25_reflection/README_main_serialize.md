# main_serialize.go

Учебная сериализация структуры в `map[string]any` через рефлексию.

Показывает:

- проверку `Kind == Struct` перед обходом полей;
- запись имени поля и `Interface()`-значения в map;
- обработку смешанных типов: скаляры, слайс, map;
- разбор `Len` / `Index` для слайса и `MapKeys` / `MapIndex` для map.

Это упрощённый учебный пример, а не полноценный `encoding/json` (нет тегов, `omitempty`, рекурсии и т.п.).

Команда:

```bash
go run main_serialize.go
```

Не запускайте `go run .`: в каталоге несколько независимых `main`.

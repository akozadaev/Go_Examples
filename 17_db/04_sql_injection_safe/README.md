# Параметризованные запросы и SQL-инъекции

Пример готовит оператор `INSERT`, передаёт данные отдельно от SQL-текста и закрывает `Stmt`. Драйвер кодирует значения как параметры, поэтому пользовательский ввод не может изменить структуру запроса.

## Запуск

```bash
go run .
```

Пример сам создаёт таблицу. Для одноразового вызова достаточно `db.Exec(query, args...)`; `Prepare` особенно полезен при многократном исполнении. Параметры защищают значения, но имена таблиц, колонок и направление сортировки требуют белого списка.

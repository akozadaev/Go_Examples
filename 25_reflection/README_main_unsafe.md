# main_unsafe.go

Базовые операции пакета `unsafe`: размеры, указатели и смещения полей.

Показывает:

- `unsafe.Sizeof` и `Alignof` для скаляров, строки, слайса и map;
- безопасное чтение через `unsafe.Pointer` с корректным типом;
- почему нельзя читать `int32` как `float64` (выход за границы объекта);
- `Offsetof` для полей структуры;
- доступ к полям через `unsafe.Add` и изменение значения по указателю.

`unsafe` обходит проверки типов компилятора, но не отменяет правила памяти и выравнивания.

Команда:

```bash
go run main_unsafe.go
```

Не запускайте `go run .`: в каталоге несколько независимых `main`.

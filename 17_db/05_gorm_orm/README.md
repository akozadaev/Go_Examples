# ORM GORM

Структура `User` становится моделью таблицы. `AutoMigrate` создаёт схему, `Create` вставляет запись, а `Find` загружает строки в срез. Режим `Debug` печатает сгенерированный SQL, что удобно для обучения.

## Запуск

```bash
go run .
```

Результаты всех операций GORM проверяются через поле `Error`. `AutoMigrate` удобен в демонстрации, но эволюцию production-схемы обычно оформляют версионированными миграциями. Файл `gorm_test.db` создаётся локально.

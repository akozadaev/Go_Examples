# Транзакции

Две вставки выполняются через один `sql.Tx`: либо фиксируются обе, либо при ошибке не фиксируется ни одна. Отложенный `Rollback` служит страховкой на всех ранних выходах; после успешного `Commit` он безопасно вернёт `sql.ErrTxDone`.

## Запуск

```bash
go run .
```

Пример автономен и сам создаёт таблицу `users`. В реальном сервисе используйте `BeginTx(ctx, &sql.TxOptions{...})`, передавайте транзакцию всем операциям сценария и не выполняйте связанные запросы через исходный `db`.

# Версионированные миграции Goose

Пример сочетает нативный `pgxpool` для прикладных запросов и адаптер `pgx/stdlib` для Goose. При запуске Goose последовательно применяет SQL-файлы из `migrations`, а затем приложение создаёт связанные записи в транзакции.

## Подготовка и запуск

Нужна база `ibs_goose` в PostgreSQL на `localhost:5432`, пользователь/пароль `ibs`/`ibs`.

```bash
go run .
```

Полезные команды из `Makefile`:

```bash
make up
make status
make down
```

Миграции должны быть монотонными и проверяться на чистой базе и на копии предыдущей схемы. Не редактируйте уже применённый файл: добавляйте следующую версию.

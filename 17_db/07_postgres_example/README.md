# PostgreSQL через `database/sql`

Пример использует классический драйвер `lib/pq`: подключается к PostgreSQL, создаёт таблицу, выполняет параметризованную вставку с плейсхолдерами `$1`, `$2` и читает `sql.Rows`.

## Подготовка и запуск

Создайте БД `testdb` и пользователя `ibs` с паролем `ibs` либо измените константы в `main.go`. Сервер ожидается на `localhost:5432`.

```bash
go run .
```

`lib/pq` находится в режиме сопровождения; для нового PostgreSQL-проекта обычно выбирают `pgx/v5`. Здесь драйвер оставлен намеренно, чтобы показать стандартный интерфейс `database/sql`.

# SQL-запросы и результаты

Пример показывает основные операции `database/sql`: создание таблицы и вставку через `Exec`, выборку нескольких строк через `Query`, чтение `Rows.Next` и преобразование колонок методом `Scan`. Значения передаются параметрами `?`, а не склеиваются со строкой SQL.

## Запуск

```bash
go run .
```

Повторный запуск добавляет ещё одного пользователя. После цикла в прикладном коде следует проверять `rows.Err()`; этот принцип подробно разобран в общей лекции.

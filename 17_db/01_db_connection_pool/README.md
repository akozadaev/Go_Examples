# Подключение к БД и пул `database/sql`

Пример открывает SQLite через драйвер `go-sqlite3`, задаёт пределы пула и проверяет доступность БД методом `Ping`. Важно: `sql.Open` создаёт объект пула, но обычно не устанавливает соединение немедленно; реальная проверка выполняется в `Ping`.

## Запуск

Нужны Go 1.26 и C-компилятор (драйвер использует CGO).

```bash
go run .
```

Файл `test.db` будет создан в текущем каталоге. В production также настраивают `SetConnMaxLifetime`, `SetConnMaxIdleTime`, таймаут контекста и наблюдают `db.Stats()`.

# Удобные запросы с sqlx

`sqlx` расширяет `database/sql`, не скрывая SQL. Пример связывает колонки со структурой по тегам `db`, выполняет именованную вставку через `NamedExec` и загружает набор строк в `[]User` методом `Select`.

## Запуск

```bash
go run .
```

Файл `sqlx_test.db` создаётся в каталоге примера. Для одного результата применяют `Get`, для динамического `IN` - `sqlx.In`, а при переносе между СУБД полезен `Rebind`.

# Нативный pgx

Пример выполняет те же базовые операции с PostgreSQL через нативный API `pgx/v5`: одно соединение `*pgx.Conn`, контекст в каждом вызове, PostgreSQL-плейсхолдеры и проверка `rows.Err()`.

## Подготовка и запуск

Нужны PostgreSQL на `localhost:5432`, пользователь/пароль `ibs`/`ibs` и база `ibs`.

```bash
go run .
```

Одно соединение подходит для демонстрации и специальных сценариев. Серверному приложению обычно нужен `pgxpool.Pool`, показанный в следующем примере.

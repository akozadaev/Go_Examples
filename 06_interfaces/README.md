# Примеры по теме «Интерфейсы»

Этот каталог содержит runnable-примеры для лекции по интерфейсам в Go.

## Запуск

```bash
cd /home/akozadaev/projects/akozadaev/go/ibs/_лонгриды/new/Go_Examples/06_interfaces
go run .
```

## Что демонстрируется

- утиная типизация;
- композиция интерфейсов;
- утверждение типов и type switch;
- внутреннее устройство интерфейса и nil trap;
- правила присваивания интерфейсам;
- безопасное и опасное приведение типов;
- практические замечания по производительности.

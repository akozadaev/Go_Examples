# Кодогенерация с `jsonenums`

## Назначение примера

Стандартный `encoding/json` кодирует именованный целочисленный enum как число, если тип не реализует специальные методы. Число `2` хуже описывает контракт API, чем строка `"PriorityHigh"`.

Этот пример создаёт JSON-кодирование для перечисления `Priority`.

- **Решаемая проблема:** необходимо передавать enum в JSON понятной строкой и безопасно восстанавливать типизированное значение.
- **Что генерируется:** методы `MarshalJSON` и `UnmarshalJSON` и таблицы соответствия между `Priority` и строками.
- **Когда полезно:** REST API, конфигурационные файлы, очереди сообщений и другие форматы, где enum должен иметь читаемое и проверяемое внешнее представление.

Результатом становятся строки `"PriorityLow"`, `"PriorityMedium"`, `"PriorityHigh"` и `"PriorityCritical"`. Неизвестная строка должна приводить к ошибке, а не незаметно превращаться в нулевое значение.

## Исходники и результат

| Роль | Файл относительно корня `go_code_generation` |
|---|---|
| Тип, константы и директива | `jsonenums_example/priority.go` |
| Сгенерированный файл | `jsonenums_example/priority_jsonenums.go` |
| Демонстрационная программа | `cmd/jsonenums/main.go` |

Директива в `priority.go`:

```go
//go:generate jsonenums -type=Priority
```

## Установка и генерация

```bash
go install github.com/campoy/jsonenums@latest
go generate ./jsonenums_example
```

Для воспроизводимой сборки следует закрепить точную версию или commit инструмента: проект обновляется нечасто. Из каталога `jsonenums_example` можно выполнить просто `go generate`. Предварительный просмотр:

```bash
go generate -n ./jsonenums_example
```

Директива запускает `jsonenums -type=Priority`. Результат создаётся рядом с исходником:

```text
jsonenums_example/priority_jsonenums.go
```

## Содержимое результата

Generated-файл реализует JSON-кодирование и декодирование, в частности методы формы:

```go
func (p Priority) MarshalJSON() ([]byte, error)
func (p *Priority) UnmarshalJSON(data []byte) error
```

После этого `encoding/json` автоматически кодирует `PriorityHigh` как строку. Поведение для неизвестной строки или числа обязательно следует покрыть тестами: корректный decoder должен вернуть ошибку, а не молча выбрать нулевое значение.

## Проверка

```bash
go run ./cmd/jsonenums
go test ./jsonenums_example
```

Демонстрация кодирует все приоритеты и проверяет ошибку для `"invalid"`. Строковые имена могут быть частью публичного API, поэтому переименование константы требует проверки совместимости. `*_jsonenums.go` исключён из Git и генерируется после чистого клонирования.

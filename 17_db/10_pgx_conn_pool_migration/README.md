# pgxpool, транзакция и встроенная миграция

SQL-схема встраивается в бинарник директивой `//go:embed`. После её применения пример валидирует аккаунты и атомарно создаёт пользователей, роли и сессии в одной транзакции `pgx.Tx`.

## Подготовка и запуск

Нужна база `ibs_migration` в PostgreSQL на `localhost:5432`, пользователь/пароль `ibs`/`ibs`.

```bash
go run .
```

Это учебная ступень между SQL в коде и полноценным инструментом миграций. Один встроенный файл не хранит историю применённых версий; эту задачу решает Goose в следующем каталоге.
